## GitHub Issues

Use GitHub Issues for:

- **Bug reports** — Something is broken
- **Feature requests** — Something you want added
- **Module/profile requests** — New tool or environment support

Before opening an issue:

1. Search existing issues to avoid duplicates
2. Check the FAQ for common questions
3. Run `./bootstrap.sh doctor` and include the output
